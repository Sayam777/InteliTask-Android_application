# InteliTask - Smart Task Manager

Android task management app with Admin/Intern roles, real-time updates & push notifications.

## Tech Stack
- Kotlin + MVVM Architecture
- Firebase Firestore, Auth, FCM, Storage
- Material Design 3 - Dark Theme

## Features
- Role-based access (Admin / Intern)
- Real-time task creation & tracking
- Push notifications
- Task priority & deadline management
